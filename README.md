# 🐍 Snake Game

A classic Snake Game built using HTML, CSS, and JavaScript.

## 🎮 About the Game

In this game, the player controls a snake that moves around the board, eats food, and grows longer. The goal is to achieve the highest score while avoiding collisions with the walls and the snake's own body.

## ✨ Features

* Classic snake gameplay
* Snake grows after eating food
* Score tracking
* Game-over detection
* Simple and responsive design
* Keyboard controls

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/snake-game.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start playing! 🎮

## 🎯 Controls

* ⬆️ Arrow Up — Move Up
* ⬇️ Arrow Down — Move Down
* ⬅️ Arrow Left — Move Left
* ➡️ Arrow Right — Move Right
